Bottom line (ELI5): G4-R exists because an earlier map-rate test compared two things that had been processed differently. The restart rebuilt that test so the maps represent the same physics before anyone trusts a later detector, Tracking, or Localization conclusion. 2. Why it matters

Bottom line (ELI5): In passive processing, the receiver can see a very loud copy of the broadcast signal. A clean-looking reduction of that loud feature is not enough; the processing must also keep the native-rate and reduced-rate maps meaningfully equivalent. Otherwise a method can make one picture look quieter while silently changing what the picture means.

The physical context is a dual-channel HDTV capture. The Reference Path is used as the reference copy of the broadcast; the Surveillance Path contains broadcast energy with a Direct Path component plus other propagation. The Direct Path can dominate the zero-delay/zero-Doppler neighborhood. The Passive Map formation question is therefore not simply “did the peak get smaller?” It is “after the stated processing, do native and reduced representations agree on common physical delay/Doppler cells?”

This distinction protects the entire downstream sequence. Direct Path suppression without common-grid preservation can move peaks, alter classifications, or redistribute energy between native and reduced representations. That makes later detector-input selection ambiguous. Conversely, a repeatable Direct Path feature is infrastructure evidence, not aircraft Measurement performance.

G4R-001Why G4-R was necessary: the prior audit compared seven native-rate ambgfun cuts with a full reduced-rate Passive Map, mixed sample-domain units, and used unlike filtering semantics. Its approximately 18 dB discrepancy could not be interpreted as signal loss or a physical map-rate limitation.

Physical-record context and boundary: S15 cancellation characterization report. Historical-comparison finding: S04 D-006 and S05 LL-007.

3. Bottom line (ELI5)

The recovery journey in one sentence: G4-R changed an incomparable test into a traceable ladder of checks; the ladder showed that the original comparison defect was correctable, but the full matrix revealed that independently resetting cancellation at native and reduced rates does not preserve the repaired map contract.

What was repaired

Both maps now use common physical support, matching filtering meaning, raw-power aggregation onto the same cells, and the same normalization definition.

What was demonstrated

Numerical oracle closure, verified synchronization reuse, a frozen production-parity checkpoint, and an integrity-audited full matrix.

What remains blocked

Formal mitigation selection, detector-input freeze, detection, future Tracking, and future Localization because the complete R5A matrix did not meet its declared criteria.

4. Technical explanation

Bottom line (ELI5): A fair map-rate comparison is not “fast map versus slow map.” It is the same physical delay/Doppler cells, the same bandwidth, the same power aggregation, and the same normalization—then a comparison of the resulting values.

What R1 through R4 required

  • R1 numerical oracle and aggregation: compare bounded full-map ambgfun output with streamed cuts after centralized raw sum/count aggregation; verify Doppler quadrature, cell-edge ownership, and CPI alignment.
  • R2 causal diagnosis: use independent CAF, aggregation, filtering/reconstruction, regional-closure, and duplicate-baseline checks to distinguish a comparison defect from a genuine reduced-rate limitation.
  • R3 verified reuse: cache G3 observations and correction only after dataset, metadata, configuration, source, evidence, and scientific-payload fingerprints agree; a mismatch must fail closed rather than refresh silently.
  • R4 frozen checkpoint: freeze fingerprints, static analysis, focused tests, production-G4 parity, regressions, and one fixed pilot before a separate matrix authorization can be considered.

6. Demonstrated work

Bottom line (ELI5): G4-R did not just diagnose a problem; it built and exercised a more reliable way to test map formation. Those pieces are real engineering output even though the current end-to-end progression is still Blocked.

Implemented

G4R-002R1 numerical-oracle and aggregation closure

A bounded full-map oracle and the corrected streamed path agreed to 6.94e-17 maximum common-cell error. One-cut and batched execution agreed to 1.39e-17. Centralized raw sum/count aggregation, boundary ownership, quadrature, and explicit CPI-alignment metadata are now part of the testable contract.

Demonstrated

G4R-002R3 provenance-safe runtime reuse

A forced G3 preparation rebuild took 411.1911 s; the median of three validated warm loads was 4.6185 s, an 89.0313× median speedup. Dataset, metadata, configuration, source, evidence, and scientific-payload fingerprints are checked before reuse.

Demonstrated

G4R-002R4 frozen production-parity checkpoint

The fixed factor-200 pilot met its frozen physical map criteria. Production-map parity was exact at 0 maximum and 0 L1 normalized-power error; the checkpoint also recorded complete G4 verification, Code Analyzer, 34/34 focused G4-R tests, 19/19 G5 regressions, and 22/22 G6-D regressions.

Primary evidence: S03 R1/R4 state, S09 R3 summary, and S10 R4 summary.

9. Meaning and interpretation

Bottom line (ELI5): R5A did not erase R4. It used the successful frozen-pilot contract to ask a bigger question, then gave a well-instrumented answer: the independently reset mitigation ordering is not stable enough across the declared map-formation domain. That is useful evidence precisely because the project stopped instead of promoting it.

The recovery has three durable implications. First, cross-rate agreement is a contract involving filtering, axes, timing, segmentation, power aggregation, and normalization—not a single correlation score. Second, runtime remediation can be scientifically safe when reuse fails closed on provenance. Third, Direct Path cancellation is sensitive to rate and adaptation ordering: a method with greater median suppression may be less acceptable if it fails common-grid preservation.

The native-first frozen-NLMS result narrows the next technical question. It does not prove that LMS is generally correct, that the collection is sufficient, or that a product should be selected. It supports only the review of a bounded upstream R4 correction, which must reproduce map-rate and regression evidence before a separately authorized replacement matrix could be considered.

12. Glossary

Bottom line (ELI5): These labels identify evidence questions and boundaries; they are not maturity badges or performance claims.

G4-R
Bounded remediation and revalidation sequence within G4, not an additional pipeline gate.
R1
Numerical oracle, aggregation, quadrature, boundary, and CPI-alignment closure.
R2
Non-gating causal diagnosis of the historical map-rate mismatch.
R3
Fail-closed reuse of validated G3 synchronization evidence plus runtime instrumentation.
R4
Frozen verification, production-parity evidence, regressions, and one fixed pilot.
R5A
Bounded exact 108-condition map-formation validation matrix.
R5B
Separate collection-suitability assessment; currently Blocked pending a reviewed ADS-B timing/geometry policy.
Reference Path
The receiver path used as the broadcast reference copy for passive processing. It is not interchangeable with the Direct Path energy that may appear in the Surveillance Path.
Surveillance Path
The receiver path examined for broadcast-related propagation, including the Direct Path and possible reflected energy.
Direct Path
Strong transmitter-to-receiver broadcast energy that can dominate a Passive Map, including the zero-delay/zero-Doppler neighborhood.
Passive Map
A passive cross-ambiguity map whose axes represent physical delay and Doppler hypotheses; it is not a validated aircraft Measurement unless downstream evidence exists.
Common-grid Passive Map
Native and reduced outputs represented on identical physical delay/Doppler cells with common power and normalization semantics.
Measurement
A validated output governed by a declared Measurement contract. This report does not claim a validated aircraft Measurement.
Tracking
Downstream association and state estimation using validated aircraft Measurements. It remains Blocked; G4-R diagnostic or infrastructure evidence does not validate Tracking.
Localization
Downstream position estimation from independently supported Measurements and geometry. It remains Blocked; G4-R diagnostic or infrastructure evidence does not validate Localization.
NLMS
Normalized least-mean-squares adaptive filter used here as a direct-path cancellation mechanism.
Frozen scoring
Train adaptive weights on a disjoint calibration record, then hold them fixed while scoring another record.
Map-preservation guard
A bounded check that a known injected-map feature remains in the expected map region; it is not a detector-performance measurement.
