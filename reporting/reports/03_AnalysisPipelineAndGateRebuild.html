1. Purpose and current status

Bottom line (ELI5): This project is rebuilding a chain of careful checks that turns a pair of HDTV radio recordings into a trustworthy aircraft measurement. Some early pieces work and several diagnostic studies have taught us useful things. The project is deliberately stopped before formal detection because one of the map-validation tests failed. That stop is evidence that the gates are protecting the result, not that the work has no value.

The stable objective is a trustworthy passive-bistatic capability that can detect and track aircraft in field data, characterize where a link can provide useful measurements, and support later multi-measurement localization. The current milestone is G4-R Map-Rate Validity and Field-Readiness Closure: a bounded remediation of the passive-map stage, not an eleventh gate. The completed R5A matrix failed its frozen criteria; the current status is retune_pending_bounded_correction. Formal G5 product selection, G6 detector-input freeze, G8 detection, objectDetection, and tracking remain disabled.

There is nevertheless specific positive evidence: the reference-session ingest contract passed; the synchronization core produced a repeatable correction model; the initial G4-R R2/R3/R4 sequence identified and corrected an invalid comparison setup; a bounded native-first frozen-NLMS R4 checkpoint passed; and a paired real-background diagnostic showed that a 15 km synthetic truth had been excluded by historical detector support before a detector decision. None of these statements is a live-aircraft detection, tracking, or localization claim.

2. Project background

Bottom line (ELI5): Passive bistatic processing listens to a broadcast that already exists. One receiver channel is the cleanest available copy of the broadcast; the other sees the same broadcast plus reflections. The system looks for a delayed, Doppler-shifted reflection that could be caused by an aircraft. That is more like finding a faint echo in a noisy room than transmitting a radar pulse and waiting for it to return.

The baseline collection is a dual-channel recording. G1 establishes what was captured and how it decodes. G2 establishes channel roles and RF/collection caveats. G3 estimates time lag, residual frequency, phase behavior, and coherence. G4 forms and validates a passive cross-ambiguity map whose axes are delay and Doppler. Subsequent gates may mitigate direct-path/interference structure, freeze a detector-input product, align truth without leaking it into detection, validate detection, determine whether detections are suitable measurements for a tracker, and finally evaluate tracks against truth.

“Localization” is broader than the present G1–G10 gate sequence. It requires trustworthy aircraft measurements, known sensor/transmitter geometry, and normally multiple suitable observations or links. It is a future system-level use of validated measurements; it is not produced by the current diagnostic artifacts.

Collection caveat that matters: the reference-session G2 work accepted a manual channel-role mapping and found analytically valid receiver data, but kept the dataset diagnostic because the reference path was weaker than surveillance and explicit lock, overrun/drop-counter, and mapping-verification evidence was missing. This is an acquisition-evidence gap, not proof that the analysis code is broken.

4. Why the gated restart happened

Bottom line (ELI5): The earlier workflow had results, but its key map-rate comparison was not comparing like with like. Before trusting any later detector result, the team rebuilt the test so the two maps represented the same physics, filtering, axes, normalization, and timing. The restart is a quality-control repair: it makes later evidence meaningful instead of merely plentiful.

The restart was motivated by two connected concerns. First, a direct-path-dominated map can be repeatable without showing useful off-origin scene structure. Second, the historical raw/reduced-rate comparison mixed unequal map semantics: an unfiltered native map was compared with an anti-alias-filtered reduced map, while earlier cut/full-map logic also mixed representations. The apparent discrepancy could not be interpreted as radar signal loss or a valid rate limit.

G4-R therefore separated numerical correctness, causal diagnosis, synchronization reuse/runtime, frozen verification, the full validation matrix, and collection suitability. It introduced independent CAF and aggregation checks, explicit orientation/filtering conventions, production-map parity, source/configuration fingerprints, compact evidence retention, and fail-closed reuse of validated G3 synchronization. The central design principle is that a corrected implementation must pass predeclared criteria before it can authorize a later study; a convenient diagnostic result cannot silently advance a formal gate.

5. Gate architecture and rationale

Bottom line (ELI5): A gate is a promise about what has been checked, not a project-management label. Passing a gate permits the next question; it does not answer every later question. Failing a gate sends work back to the smallest earlier question that can fix the problem.

G1–G10 are the stable pipeline gates. G4-R is a remediation ladder inside G4. The ladder deliberately prevents an R4 pilot or an attractive close-target diagnostic from being reinterpreted as formal G5/G6/G8 authorization. R5A validates map formation in an exact 108-condition matrix; R5B independently evaluates collection suitability under a reviewed numerical ADS-B timing/geometry policy. Both are necessary to close the relevant aspects of G4, and neither validates the complete pipeline.

Primary evidence: S04 G4-R plan, S13 failed R5A summary, S05 D-014.

8. Current evidence boundaries

Bottom line (ELI5): A controlled synthetic echo in a real recording is very useful for testing the plumbing. It is not the same as proving that the system detects arbitrary live aircraft in all field conditions.

The strongest narrow diagnostic result is deliberately truth-separated: the system forms the map, applies CFAR, and applies nonmaximum suppression without generated truth. Only afterward is the known synthetic target used to associate an already-retained candidate. The paired untouched control asks whether that same target-specific window contains an associated candidate; it is not a map-wide false-alarm measurement.

Similarly, the PBR-SVE opportunity figures are based on sampled ADS-B/geometry states. They quantify which states would lie in a specified support rectangle; they do not run CFAR, inject signals, measure aircraft detection performance, or establish localization-capable coverage.

This report establishes:
  • the intended pipeline and evidence ownership;
  • why G4-R was necessary and what it is protecting;
  • specific early-stage and bounded diagnostic results;
  • the exact dependency path that prevents formal aircraft measurement generation today.
This report does not establish:
  • live-aircraft detection performance;
  • operational probability of detection or operational false alarm rate;
  • a selected mitigation product or frozen detector input;
  • tracking performance, track-to-truth quality, localization performance, or localization accuracy;
  • hardware or site sufficiency.

Primary evidence: S05 D-003, S16 diagnostic method and limits, S17 opportunity boundaries.

9. Project value delivered so far

Bottom line (ELI5): The value so far is not a claim that aircraft are ready to track. It is a tested way to avoid building a tracking or localization demo on untrustworthy measurements—and a set of concrete findings that tell the team exactly where to work next.

  • Reproducible engineering contracts: the project can trace source files, configuration, map semantics, acceptance checks, and compact outputs instead of relying on a single attractive visualization.
  • Root-cause discrimination: G4-R separated an invalid comparison implementation from a presumed physical limitation, then kept the later matrix failure as a distinct, product-specific finding.
  • Evidence-preserving safety: downstream refusal scaffolds prevent diagnostic detector work from being mistaken for formal detection readiness.
  • Better collection and support questions: G2 identifies missing acquisition evidence; PBR-SVE describes sampled geometry/opportunity; the close-target study identifies a support-policy exclusion rather than calling it a detector miss.
  • Efficient, provenance-safe iteration: validated G3 reuse reduces repeatable setup time without silently changing inputs.

Primary evidence: S06 lessons learned, S03 verified current state.

10. What remains before aircraft measurement generation

Bottom line (ELI5): Before the system can issue a trusted aircraft measurement, it must first prove that the map is reliable, choose and freeze the exact product that feeds the detector, define how truth is aligned for validation, and then validate the detector without letting truth steer it. The current close-target diagnostic helps explain one issue, but it cannot skip these steps.

The next work is a dependency chain, not a collection of independent improvements. The first active decision is whether to adopt the evidence-supported native-first frozen-NLMS ordering as a bounded upstream R4 correction. If approved, it must be reverified under the existing map contract and regressions. Only then can a separately authorized replacement R5A matrix be considered. Collection suitability (R5B) remains a separate block until a reviewed ADS-B timing/geometry policy exists.

Major technical blocker: R5A’s 108-condition matrix is integrity-valid but failed the frozen map-rate criteria. The observed candidate correction must not be adopted without a reviewed R4 re-verification.
Major evidence gap: collection suitability is independently blocked pending a reviewed numerical ADS-B timing/geometry policy; G2 also preserves missing acquisition-state evidence as a caveat.
Formal detection gap: no formal G5 product is selected, no G6 detector input is frozen, G7 product-level truth claims are disabled, and G8 currently refuses formal execution.
Later-use gap: no validated measurement contract exists for G9; therefore no tracker performance, track-to-truth validation, or localization accuracy can be claimed.

Primary evidence: S03 current blocker and next action, S13 R5A failure, S18 G6 refusal, S20 G8 refusal.

11. Meaning and limits

Bottom line (ELI5): The restart has produced meaningful engineering progress because it changed unknowns into tested, traceable facts. It has not yet produced the kind of validated aircraft measurement that a tracker or localization system should consume.

The report’s central interpretation is therefore two-part. First, the project has a defendable basis for continuing: it has instrumented early gates, demonstrated bounded G4-R correction and diagnostic workflows, protected truth separation, and located specific collection/map/support questions. Second, it must retain the formal stop because the map-formation matrix failed and the downstream contract has not been frozen or validated.

This distinction is useful to a manager: it preserves the value of evidence already produced while making the resource and decision path to the next milestone explicit. It also prevents later tracking/localization work from becoming a visually compelling but unvalidated demonstration.

Bottom line (ELI5): The labels below are shorthand for evidence questions. They are not maturity badges.

G3 — Sync
Establish channel roles, lag, residual-frequency correction, and coherence.
G4 — Passive baseline map
Validate passive-map formation, axes, repeatability, and map-rate equivalence.

Compare direct-path/interference mitigation candidates without losing required target/map content.

Select and freeze CPI, overlap/integration rules, and the detector-input product.
