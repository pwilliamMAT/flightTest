# FlightTest Source Materials

Start here to find shared FlightTest presentations, engineering data, and
large evidence bundles.

[FlightTest Datasets and Presentations](https://mathworks.sharepoint.com/:f:/r/sites/spc/signal/RadarToolbox/Shared%20Documents/Data/FlightTest%20Datasets%20and%20Presentations?d=wfe2816fad8cd4aa88a4cea5271af71bb&csf=1&web=1&e=HKMaVG)
is the shared project location.

## Expected contents

- **Project and engineering presentations:** project overview, illuminator
  selection, RF-budget, receive-chain, hardware, and manager-review decks.
- **Engineering data and analysis files:** transmitter lists, link-budget and
  coverage data, RF-budget models, and supporting spreadsheets.
- **Collection packages:** dual-channel IQ recordings, ADS-B and GPS/NMEA
  truth, collection logs, and session manifests.
- **Controlled analysis evidence:** synthetic-condition manifests, maps,
  recovery atlases, images, and summary outputs.

Use the shared location above when you need source material for FlightTest.
