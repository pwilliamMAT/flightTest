# Template: CONOPS Brief

Use this to define the operational concept before requirements are written.

Do not use this artifact to record solved technical findings, decoded answers, or implementation results.

This artifact requires a companion `System Composer` `System Context Diagram`.

Allowed content in the diagram:
- operator, user, or stakeholder
- system-of-interest boundary
- external systems or services
- primary inputs and outputs
- high-level operational interactions or scenarios
- explicit out-of-scope or adjacent systems when useful

Not allowed in the diagram:
- algorithms
- code structure
- class or module decomposition
- detailed internal components
- test design
- implementation sequencing
