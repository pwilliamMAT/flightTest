# ADS-B Neural Kalman Concepts

This index maps each implemented concept to the MATLAB files that demonstrate it.

| Concept | Description | Implemented In |
| :--- | :--- | :--- |
| **Recursive Position-Updated Filter Evaluation** | Stage 4E turns one-step motion models into complete recursive estimators. Native CV, CA, and CT `trackingEKF` filters, a native `trackingIMM`, and a frozen-warm `trackingUKF` receive matched position updates and coast through matched dropouts. `trackingFilterTuner` uses validation events only; synthetic sequences are scored against latent truth, while reserved held-out ADS-B reports remain a clearly labeled scoring proxy. The review reports error, consistency, covariance validity, outage-age response, runtime, and optional `trackingGlobeViewer` paths without evaluating association or passive-radar detections. | `stage4ERecursiveFilterEvaluationLiveScript.m`, `runStage4ERecursiveFilterEvaluation.m`, `helperTuneStage4EFilters.m`, `helperInitializeStage4EFilter.m`, `helperEvaluateStage4ESequences.m`, `helperStage4EWarmTransition.m`, `helperPlotStage4ERecursiveEvaluation.m`, `helperBuildStage4EGlobeReview.m`, `helperOpenStage4EGlobe.m`, `tests/Stage4ERecursiveFilterEvaluationTest.m` |
| **Frozen Warm-Model Characterization** | Stage 4D freezes `expanded_warm_mean_v1` and compares it with native `constvel`, `constacc`, and `constturn` across 21 canonical cases, 100 ten-minute in-distribution trajectories, 50 ten-minute out-of-distribution trajectories, and held-out real ADS-B dropout tests. Synthetic truth is generated with `kinematicTrajectory`; warm versus `constvel` is the same-information headline, while predecessor-assisted CA/CT metrics remain separate. Static robustness summaries are complemented by interactive `trackingGlobeViewer` collections for all seven canonical motions and one selectable held-out ADS-B dropout event. Each globe overlays input, scoring reference, warm, `constvel`, `constacc`, and `constturn` paths while preserving the one-step—not recursive-track—interpretation. | `stage4DFrozenWarmCharacterizationLiveScript.m`, `runStage4DFrozenWarmCharacterization.m`, `helperGenerateStage4DSyntheticBenchmark.m`, `helperBuildStage4DRealDropoutBenchmark.m`, `helperEvaluateStage4DPredictors.m`, `helperPlotStage4DCharacterization.m`, `helperBuildStage4DGlobeReview.m`, `helperOpenStage4DGlobe.m`, `tests/Stage4DFrozenWarmCharacterizationTest.m` |
| **Local ADS-B State-Pair Dataset** | SBS-1 ADS-B truth tracks are parsed with the existing `loadADSBTruth` parser, converted from WGS-84 geodetic coordinates into local ENU meters with `wgs84Ellipsoid` and `geodetic2enu`, and exported as one-step state pairs in Sensor Fusion order `[x, vx, y, vy, z, vz]`. The velocity convention is `vx = speed_mps * sind(track_deg)`, `vy = speed_mps * cosd(track_deg)`, and `vz = vrate_mps`. | `buildLocalADSBStatePairDataset.m`, `helperBuildLocalADSBStatePairs.m` |
| **Constant-Velocity Prediction Baseline** | The native Sensor Fusion and Tracking Toolbox `constvel(state, dt)` model predicts each irregular one-step pair without manually reconstructing the motion equations. Physical-unit position and velocity errors are saved as baseline smoke metrics. | `helperScoreConstVelBaseline.m` |
| **Maneuver-Aware State-Pair Characterization** | Existing Stage 2B state pairs are labeled using velocity-vector heading change, horizontal speed change, vertical-rate change, climb/descent status, and sparse-update status. The labels align examples with native `constvel`, `constacc`, and `constturn` model assumptions for stratified baseline reporting. | `runStage2CManeuverCharacterization.m`, `helperAssignADSBManeuverLabels.m`, `helperScoreConstVelByManeuverClass.m`, `helperWriteStage2CReport.m` |
| **Unified Stage 4C Review Dashboard** | The plain-text Stage Review Live Script is the single Run All entry point for the frozen Expanded-3Day split and motion-class cross-tabulation, a test-only native-versus-neural position/velocity RMSE dashboard, a separate neural-only validation-versus-test dashboard, and independent configurable `trackingGlobeViewer` collections for `constvel_like`, `constacc_like`, and `constturn_like` test events. `stage4CGlobeTrajectoryCount = N` selects the longest `N` eligible continuous events per class, capped at availability; each viewer draws `5N` paths in five batched `plotTrajectory` calls: truth, the class-aligned native model, Stage 3A, Expanded scratch, and Expanded warm. “Test” on a native result names the evaluated data partition; it does not imply native-model training or validation. ENU predictions are converted with `enu2geodetic` and represented with `geoTrajectory`; no training, clipping, smoothing, recursive forecasting, or tracker output is introduced. | `stageReviewLiveScript.m`, `helperBuildStage4CReviewDashboard.m`, `helperBuildStage4CTrajectoryCollection.m`, `helperPlotStage4CRMSEDashboard.m`, `helperPlotStage4CNNValidationTest.m`, `helperOpenStage4CReviewGlobe.m`, `tests/StageReviewLiveScriptTest.m` |
| **Minimal Diagonal-Covariance MLP Smoke Interface** | A small Deep Learning Toolbox MLP consumes normalized previous state, assumed covariance diagonal, and elapsed time. It outputs a normalized next-state mean plus six raw variance parameters; `softplus(rawVariance) + epsilon` guarantees strictly positive diagonal covariance values for Gaussian NLL smoke training. | `trainLocalADSBMLPSmoke.m` |
| **Delta-Target MLP Training Workflow** | Stage 3A trains a MATLAB `trainnet` MLP to predict `targetDelta = nextState - previousState` from motion-focused features, then reconstructs `predictedNextState = previousState + predictedDelta`. It compares zero-delta, train-mean, native `constvel`, linear regression, raw-feature MLP, and physics-derived-feature MLP results, with maneuver-class and split diagnostics from Stage 2C. | `trainLocalADSBMLPStage3.m`, `helperBuildStage3AFeatures.m`, `helperScoreStage3APredictions.m`, `helperWriteStage3AReport.m`, `helperWriteStage3AFigures.m` |
| **Stage 3B Aggregate Evaluation Gate** | Stage 3B aggregates all currently discoverable local ADS-B truth files, evaluates the frozen Stage 3A delta-target MLP against native `constvel` on identical state-pair rows, plots all row-wise position absolute errors in the Stage 3A blue/red comparison convention, reports grouped physical-unit errors, and gates future retraining on session, source, aircraft, maneuver, climb/descent, and sparse-update diversity. | `runStage3BAggregateADSBEvaluation.m`, `helperWriteStage3BReport.m`, `helperWriteStage3BFigures.m`, `helperPlotStage3BPositionAbsError.m`, `helperOpenStage3BGlobe.m` |
| **Stage 3C Archived ADS-B Evaluation Extension** | Stage 3C evaluates `adsb_archive/adsb_archive` without retraining. It inventories `testing_machine/captures/<session_id>/truth` and empty `pi_only/truth`, uses MATLAB `gunzip` first with a .NET fallback only after native gzip failure, reuses Stage 3B frozen Stage 3A versus `constvel` scoring, and writes archive-readiness figures and reports. | `runStage3CArchiveADSBEvaluation.m`, `helperBuildStage3CArchiveInventory.m`, `helperWriteStage3CReport.m`, `helperWriteStage3CFigures.m`, `../BistaticDataAnalysis/helperInflateGzipWithDotNet.m`, `tests/Stage3CArchiveEvaluationTest.m` |
| **Stage 4A ADS-B Truth Capture Planning** | Stage 4A prefers the saved Stage 3C archive artifact, falls back to Stage 3B for compatibility, and answers capture-readiness questions through plots: basic gates, motion/update coverage, constvel-versus-frozen-MLP RMSE by regime, split coverage, Pi-only versus testing-machine source coverage, receiver-origin metadata coverage, and targeted collection status. It directs the next action to independent Pi-only holdout capture and metadata-preserving packaging instead of retraining. | `stage4ADSBTruthCapturePlanningLiveScript.m`, `helperBuildStage4ADSBTruthCapturePlan.m`, `helperPlotStage4ADSBTruthCapturePlan.m` |
| **Stage 4B ADS-B Interval Capture Campaign** | Stage 4B adds a testing-machine coordinator for ADS-B-only interval capture windows. It SSHes to the Pi, delegates each bounded window to the existing logger wrapper, fetches gzip truth logs with `scp`, and packages `captures/<session_id>/session_manifest.json` with numeric `receiver_origin_lla` metadata for each holdout session. | `piCaptureCampaign/run_stage4_adsb_interval_campaign.sh`, `piCaptureCampaign/README.md`, `tests/Stage4BADSBIntervalCampaignScriptTest.m` |
| **Versioned ADS-B Dataset Integration and Motion-Diversity Gate** | Stage 4B-Post preserves the historical **Legacy-16**, the new **3-Day Campaign Increment**, and their **Expanded-3Day** union as hash-verified, independently rerunnable variants. It evaluates the frozen Stage 3A MLP against native `constvel`, segments sustained turn/acceleration/climb/descent and sparse-gap events, measures contributor concentration and joint-regime occupancy, audits aircraft-disjoint and chronological splits, and reports local-retraining readiness separately from broad-generalization readiness. | `integrateStage4BThreeDayArchive.m`, `runADSBDatasetVariantEvaluation.m`, `runStage4BPostCampaignMotionDiversityGate.m`, `helperAnalyzeADSBDatasetMotionDiversity.m`, `helperSegmentADSBMotionEvents.m`, `helperAuditADSBProspectiveSplits.m`, `helperWriteStage4BPostCampaignFigures.m`, `helperWriteStage4BPostCampaignReport.m`, `tests/Stage4BPostDatasetTest.m` |
| **Causal Native Maneuver Baselines** | The Stage 4C evaluation-only extension estimates raw 3-D acceleration and wrapped heading rate from the immediately preceding observation in the same session/ICAO, then propagates native `constacc` and `constturn` states. It excludes first rows, temporal gaps, split mismatches, nonpositive prior intervals, and nonfinite values; scores all five models on identical eligible validation/test rows with pair and independent-event weighting; and reports unclipped finite-difference tails so turn-rate spike sensitivity remains visible. Retrospective maneuver labels select evaluation slices only. | `runStage4CNativeManeuverBaselineEvaluation.m`, `helperBuildStage4CNativeManeuverBaselines.m`, `helperScoreStage4CNativeManeuverModels.m`, `helperWriteStage4CNativeManeuverFigure.m`, `helperWriteStage4CRetrainReport.m`, `tests/Stage4CNativeManeuverBaselineEvaluationTest.m` |
| **Expanded-3Day Exploratory Mean-MLP Retraining** | Stage 4C trains the unchanged memoryless 20–64–64–6 delta MLP on a frozen global ICAO-disjoint split. A scratch candidate and a normalization-rebased Stage 3A warm-start control use identical `trainnet` options and fresh Adam state. Untouched validation/test rows are compared with native `constvel` and the frozen Stage 3A network using pair-weighted and independent-event-weighted position/velocity RMSE, median, and P95 across maneuver, vertical-flight, and update-rate regimes. | `runStage4CRetrainExpandedADSBMLP.m`, `helperBuildStage4CFeatures.m`, `helperRebaseStage3ANetworkNormalization.m`, `helperScoreStage4CMeanModels.m`, `helperWriteStage4CRetrainFigures.m`, `helperWriteStage4CRetrainReport.m`, `tests/Stage4CRetrainExpandedADSBMLPTest.m` |
