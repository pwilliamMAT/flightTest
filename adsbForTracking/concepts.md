# ADS-B Neural Kalman Concepts

This index maps each implemented concept to the MATLAB files that demonstrate it.

| Concept | Description | Implemented In |
| :--- | :--- | :--- |
| **Local ADS-B State-Pair Dataset** | SBS-1 ADS-B truth tracks are parsed with the existing `loadADSBTruth` parser, converted from WGS-84 geodetic coordinates into local ENU meters with `wgs84Ellipsoid` and `geodetic2enu`, and exported as one-step state pairs in Sensor Fusion order `[x, vx, y, vy, z, vz]`. The velocity convention is `vx = speed_mps * sind(track_deg)`, `vy = speed_mps * cosd(track_deg)`, and `vz = vrate_mps`. | `buildLocalADSBStatePairDataset.m`, `helperBuildLocalADSBStatePairs.m` |
| **Constant-Velocity Prediction Baseline** | The native Sensor Fusion and Tracking Toolbox `constvel(state, dt)` model predicts each irregular one-step pair without manually reconstructing the motion equations. Physical-unit position and velocity errors are saved as baseline smoke metrics. | `helperScoreConstVelBaseline.m` |
| **Maneuver-Aware State-Pair Characterization** | Existing Stage 2B state pairs are labeled using velocity-vector heading change, horizontal speed change, vertical-rate change, climb/descent status, and sparse-update status. The labels align examples with native `constvel`, `constacc`, and `constturn` model assumptions for stratified baseline reporting. | `runStage2CManeuverCharacterization.m`, `helperAssignADSBManeuverLabels.m`, `helperScoreConstVelByManeuverClass.m`, `helperWriteStage2CReport.m` |
| **Stage Review Live Script** | A plain-text MATLAB Live Script explains the latest Stage 1 through Stage 3B workflow, compares ADS-B next-state truth against native `constvel`, the saved Stage 2B smoke MLP output, the optional Stage 3A delta-target MLP output, and the optional Stage 3B aggregate evaluation output, documents MATLAB MLP training details, and includes static plots, Stage 3A and Stage 3B comparison sections, the Stage 3B position-absolute-error separation plot, and a `trackingGlobeViewer` snapshot review section. | `stageReviewLiveScript.m`, `helperBuildStageReviewArtifacts.m`, `helperBuildStageReviewTrainingDetails.m`, `helperBuildStageReviewMLPDiagnostics.m`, `helperBuildStageReviewTrackDiagnostics.m`, `helperBuildStageReviewTrajectories.m`, `helperOpenStageReviewGlobe.m`, `helperPlotStageReviewStage3ErrorComparison.m`, `helperPlotStage3BPositionAbsError.m` |
| **Minimal Diagonal-Covariance MLP Smoke Interface** | A small Deep Learning Toolbox MLP consumes normalized previous state, assumed covariance diagonal, and elapsed time. It outputs a normalized next-state mean plus six raw variance parameters; `softplus(rawVariance) + epsilon` guarantees strictly positive diagonal covariance values for Gaussian NLL smoke training. | `trainLocalADSBMLPSmoke.m` |
| **Delta-Target MLP Training Workflow** | Stage 3A trains a MATLAB `trainnet` MLP to predict `targetDelta = nextState - previousState` from motion-focused features, then reconstructs `predictedNextState = previousState + predictedDelta`. It compares zero-delta, train-mean, native `constvel`, linear regression, raw-feature MLP, and physics-derived-feature MLP results, with maneuver-class and split diagnostics from Stage 2C. | `trainLocalADSBMLPStage3.m`, `helperBuildStage3AFeatures.m`, `helperScoreStage3APredictions.m`, `helperWriteStage3AReport.m`, `helperWriteStage3AFigures.m` |
| **Stage 3B Aggregate Evaluation Gate** | Stage 3B aggregates all currently discoverable local ADS-B truth files, evaluates the frozen Stage 3A delta-target MLP against native `constvel` on identical state-pair rows, plots all row-wise position absolute errors in the Stage 3A blue/red comparison convention, reports grouped physical-unit errors, and gates future retraining on session, source, aircraft, maneuver, climb/descent, and sparse-update diversity. | `runStage3BAggregateADSBEvaluation.m`, `helperWriteStage3BReport.m`, `helperWriteStage3BFigures.m`, `helperPlotStage3BPositionAbsError.m`, `helperOpenStage3BGlobe.m` |
| **Stage 3C Archived ADS-B Evaluation Extension** | Stage 3C evaluates `adsb_archive/adsb_archive` without retraining. It inventories `testing_machine/captures/<session_id>/truth` and empty `pi_only/truth`, uses MATLAB `gunzip` first with a .NET fallback only after native gzip failure, reuses Stage 3B frozen Stage 3A versus `constvel` scoring, and writes archive-readiness figures and reports. | `runStage3CArchiveADSBEvaluation.m`, `helperBuildStage3CArchiveInventory.m`, `helperWriteStage3CReport.m`, `helperWriteStage3CFigures.m`, `../BistaticDataAnalysis/helperInflateGzipWithDotNet.m`, `tests/Stage3CArchiveEvaluationTest.m` |
| **Stage 4A ADS-B Truth Capture Planning** | Stage 4A prefers the saved Stage 3C archive artifact, falls back to Stage 3B for compatibility, and answers capture-readiness questions through plots: basic gates, motion/update coverage, constvel-versus-frozen-MLP RMSE by regime, split coverage, Pi-only versus testing-machine source coverage, receiver-origin metadata coverage, and targeted collection status. It directs the next action to independent Pi-only holdout capture and metadata-preserving packaging instead of retraining. | `stage4ADSBTruthCapturePlanningLiveScript.m`, `helperBuildStage4ADSBTruthCapturePlan.m`, `helperPlotStage4ADSBTruthCapturePlan.m` |
| **Stage 4B ADS-B Interval Capture Campaign** | Stage 4B adds a testing-machine coordinator for ADS-B-only interval capture windows. It SSHes to the Pi, delegates each bounded window to the existing logger wrapper, fetches gzip truth logs with `scp`, and packages `captures/<session_id>/session_manifest.json` with numeric `receiver_origin_lla` metadata for each holdout session. | `piCaptureCampaign/run_stage4_adsb_interval_campaign.sh`, `piCaptureCampaign/README.md`, `tests/Stage4BADSBIntervalCampaignScriptTest.m` |
