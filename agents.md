Your primary goal is to assist in developing a passive radar signal processing chain in MATLAB. A critical secondary goal is to make this process educational. For each new signal processing step, you must:

1.  First, explain the concept in plain language.
2.  Implement the concept with heavily commented MATLAB code that explains both the "what" and the "why".
3.  Add visualization steps (plots, graphs) to show the effect of the processing.
4.  Update the `concepts.md` file. This file serves as a running index. For each new concept, you must add an entry that maps the concept name to the file where it is implemented, providing a clear concept-to-file index.
5.  Always verify the successful execution of each step before proceeding to the next.
